# Service hover images

Drop a photo here named after the service slug and it appears behind that card
on hover. No code change needed.

Guidance:
- Landscape, around 900x700, JPEG, under ~120 KB each.
- Composition matters more than subject: the image is desaturated and washed
  back behind a colour overlay, so busy or high-contrast shots turn to mush.
  Simple scenes with one clear subject read best.
- A missing file paints nothing at all -- the card just keeps its line icon,
  with no broken-image state. Add them one at a time if that is easier.
